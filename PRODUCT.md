# TrialLens product context
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Case owners and lawyers/legal reviewers. The user confirmed both audiences, a simple default, and advanced controls on 6 November 2026.

## Product Purpose
Upload a case, review the permitted record, inspect a simulated jury decision and its sources, then save and reopen the case.

## Brand Commitments
TrialLens, restrained burgundy and ink on white, one readable sans-serif family. Preserve the local evidence-review identity.

## Constraints
Generated output is research and rehearsal, not a real verdict prediction. Preserve source permissions, model approval, external disclosure consent, saved histories and existing archive/API formats. Incomplete runs never become verdicts. Optional courtroom features stay gated.

## Approved scope
The user approved the 6 November UX proposal and Results/source composition and authorized implementation, checks, review, merge to main and an Atlassian update. Use Overview / Documents / Simulation / Results, guided setup, source inspection beside a reason, truthful save feedback, and advanced controls. Do not merge the independent draft validator changes in PR #10 as part of this UI work.
